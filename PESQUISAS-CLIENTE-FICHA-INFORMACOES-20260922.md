# Pesquisas disponíveis do cliente — 22/09/2026

O seletor de pesquisa do perfil cliente foi ampliado para apresentar todas as pesquisas vinculadas ao cliente em uma lista própria. A lista mostra o nome, o tipo e o status de cada pesquisa disponível.

Ao clicar em uma pesquisa, o cliente visualiza uma ficha detalhada antes de selecioná-la. A ficha apresenta período, amostra prevista, margem de erro, nível de confiança, abrangência geográfica, quantidade de perguntas e, quando aplicável, o estado de liberação dos resultados.

A ação **Selecionar pesquisa** define a pesquisa ativa do perfil. As páginas de Andamento, Resultados e Aprovar formulário continuam usando essa seleção. A ação **Abrir andamento** aparece para a pesquisa já ativa e leva diretamente à área de acompanhamento.

A alteração é exclusivamente de interface e leitura dos dados já vinculados à pesquisa. Nenhuma migration SQL foi criada, executada ou modificada.
