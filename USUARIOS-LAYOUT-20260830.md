# Usuários — atualização visual 2026-08-30

A página de Usuários recebeu uma camada de interface orientada à gestão de perfis. Cada aba passa a apresentar contexto próprio, contagem de registros, estado ativo com `aria-current`, cards de resumo e uma área de tabela com cabeçalho explicativo.

## Principais mudanças

As abas agora mostram contadores por categoria e permanecem navegáveis horizontalmente em telas menores. A categoria atual é apresentada como contexto operacional, com descrição específica para pesquisadores, clientes, equipe interna, vendedores, indicadores e administração.

Os cards de resumo foram reorganizados para destacar total cadastrado, ativos e pendentes. A tabela ganhou cabeçalho visual, contagem de registros, rolagem horizontal segura e estados de linha mais claros.

Quando a categoria está vazia, a página não exibe somente uma mensagem central: mostra título orientativo, explicação do próximo passo e botão de cadastro contextual. Isso facilita o início do fluxo para indicadores e vendedores.

O layout se adapta para tablet e celular, com abas roláveis, contexto empilhado, tabela protegida contra overflow e estado vazio reorganizado verticalmente.

## Compatibilidade

A alteração é visual e não muda os contratos do banco nem a lógica de criação, edição, aprovação ou exclusão de usuários. Os campos de comissão existentes para vendedor e indicador continuam acessíveis pelo formulário administrativo.
